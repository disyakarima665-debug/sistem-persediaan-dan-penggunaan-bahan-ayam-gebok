Sistem Persediaan & Cost adalah aplikasi manajemen stok dan biaya operasional yang dirancang khusus untuk usaha kuliner seperti ayam geprek, warung, restoran, hingga bisnis UMKM. Aplikasi ini membantu pemilik usaha dalam mencatat persediaan bahan baku, memantau stok minimum, mencatat transaksi masuk/keluar barang, serta menganalisis biaya operasional secara lebih efisien.

## Why This Project?

Banyak usaha mikro dan kecil masih mencatat stok dan biaya secara manual menggunakan buku atau spreadsheet. Hal ini sering menyebabkan:
- stok barang tidak terpantau dengan akurat
- pembelian dan pemakaian bahan tidak terdokumentasi
- biaya operasional sulit dilacak
- laporan harian memakan waktu lama

Dengan sistem ini, proses pencatatan bisa dilakukan secara lebih cepat, rapi, dan terstruktur.

## Key Features

- Dashboard utama untuk monitoring operasional
- Manajemen cabang
- Manajemen bahan baku
- Pencatatan barang masuk
- Pencatatan barang keluar
- Alert stok minimum
- Rekap harian
- Riwayat transaksi
- Laporan cost dan pembiayaan operasional
- Export data ke Excel/PDF
- Mode demo dan integrasi Supabase

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Database: PostgreSQL (via Supabase)
- API: REST API
- Deployment: GitHub Pages / Vercel / Netlify / hosting lainnya
